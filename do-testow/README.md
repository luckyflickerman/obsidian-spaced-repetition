# Plugin do testów (zbudowany z tej gałęzi)

Gotowe pliki pluginu Fishcards do sprawdzenia w `dev-vault` — bez budowania.

1. Skopiuj **zawartość** folderu `upgraded-spaced-repetition` (pliki `main.js`, `manifest.json`, `styles.css`)
   do `dev-vault\.obsidian\plugins\upgraded-spaced-repetition\` i zgódź się na zastąpienie plików.
   Nie usuwaj tam pliku `data.json`.
2. W Obsidianie z otwartym `dev-vault`: Ustawienia → Wtyczki społeczności → Fishcards wyłącz i włącz.

Folder `.obsidian` jest ukryty: w Eksploratorze Windows włącz Widok → Pokaż → Ukryte elementy.
Ten folder jest tylko do testów — przed wydaniem wersji można go usunąć.
