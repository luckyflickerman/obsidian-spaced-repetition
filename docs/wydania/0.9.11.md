# Wydanie 0.9.11 — nowa nazwa „Fishcards”, poprawka listy trybów (podsumowanie dla przyszłych sesji)

Poprzednie: [0.9.10](0.9.10.md). Zmiany widoczne dla użytkowniczki: `CHANGELOG-UPGRADED.md`, sekcja `## 0.9.11`.

## Co weszło

- **Nazwa „Fishcards”** (gra słów „fiszki” + _flashcards_; wybrana przez użytkowniczkę 8.10.2026). Zmienione: `manifest.json` → `name` i `description` (opis zaczyna się od czasownika, 146 znaków, kropka na końcu — zgodnie z wymaganiami katalogu), `SETTINGS_HEADER` we wszystkich językach, tytuł karty widoku (`sr-tab-view.tsx`), okno Opcji, podpowiedź „brak talii”, README, SPEED-STREAK-README, CLAUDE.md. **Identyfikator `upgraded-spaced-repetition` bez zmian** (ustawienia, dane, komendy zostają). Domyślny folder danych harmonogramu `"Spaced Repetition"` w `settings.ts` celowo bez zmian (dane użytkowników).
- **Lista trybów z tłem**: rozwinięta lista `<select>` jest rysowana przez system (biała na Windows), a `<option>` dziedziczył jasny `--usr-bg-ink` → prawie niewidoczne „Tryb intensywny” i „Endless”. W `background.css`: `.usr-bg-on select.dropdown option { background-color: rgb(var(--usr-bg-base)); color: var(--usr-bg-ink); }`. Na macOS systemowa lista może ignorować kolory — wtedy i tak ma systemowe, czytelne barwy.
- **README** przepisane: Fishcards, aktualne funkcje (Time Boost domyślnie wyłączony, Endless z kartą rekordu i „Trudne” = 0, cztery motywy, układ na komputerze/iPadzie/telefonie), „Getting started”, autorzy oryginału (Stephen Mwangi, Kyle Klus). Nowe zrzuty: `docs/screenshots/endless-record-phone.png`, `theme-space-phone.png`, `theme-aurora-phone.png`.
